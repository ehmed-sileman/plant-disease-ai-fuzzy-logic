# Plant Disease Detection and Treatment Tracking Using AI and Fuzzy Logic

Graduation project in Artificial Intelligence by **Ehmed Silêman**.

## Overview

This project presents an intelligent system for detecting plant diseases
by analyzing images of plant leaves.

The user captures or uploads an image of a plant leaf, and an Artificial
Intelligence model analyzes the image to detect the possible disease.

The system also uses Fuzzy Logic as part of the treatment tracking and
decision-support process.

## Main Features

- Plant leaf image analysis
- AI-based disease detection
- Image classification
- Plant disease identification
- Treatment tracking
- Fuzzy Logic decision support
- Disease and treatment information
- Application-based user interface

## Artificial Intelligence

The system uses an image-based Artificial Intelligence model to analyze
plant leaves and identify diseases based on visual symptoms.

## Fuzzy Logic

Fuzzy Logic is used in the treatment follow-up process to evaluate multiple
conditions and support treatment-related decisions using fuzzy rules.
